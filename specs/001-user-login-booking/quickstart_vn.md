# Quickstart: User Login Booking

## Manual Setup

- Chạy Prisma migrations sau khi cập nhật code (thêm booking ownership và customer role).

## Verification

- Thử booking khi chưa đăng nhập → bị chặn hoặc chuyển tới đăng nhập.
- Đăng nhập và hoàn tất booking → booking được gắn với user.
- Mở My Bookings → chỉ thấy booking của user hiện tại.
