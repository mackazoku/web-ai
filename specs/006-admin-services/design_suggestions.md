# Design Suggestions: Admin Services Screen

## Suggestions
- ID: D-001
  - Title: Bento grid consistency
  - Description: Use a consistent bento grid rhythm (large hero card + smaller cards + insight block) for visual hierarchy.
  - Scope impact: Services layout and spacing.
  - Related screens/features: Admin Services.
  - Trade-offs: Layout constraints vs. stronger visual coherence.
  - Estimated complexity: Low
  - Status: approved
  - Owner decision: approved
- ID: D-002
  - Title: Status pill system
  - Description: Standardize status pills for Active/Draft/Hidden across admin screens.
  - Scope impact: Status styling and i18n labels.
  - Related screens/features: Admin Services, other admin lists.
  - Trade-offs: Extra design system work vs. consistency.
  - Estimated complexity: Medium
  - Status: approved
  - Owner decision: approved
