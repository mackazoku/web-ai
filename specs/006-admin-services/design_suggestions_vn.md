# Design Suggestions: Màn hình Services (Admin)

- ID: D-001
  - Title: Nhịp bento grid nhất quán
  - Description: Duy trì nhịp bento grid (thẻ lớn + thẻ nhỏ + khối insight) để tạo thứ bậc thị giác.
  - Scope impact: Layout và spacing màn hình Services.
  - Related screens/features: Admin Services.
  - Trade-offs: Ràng buộc layout vs. tính nhất quán cao hơn.
  - Estimated complexity: Low
  - Status: approved
  - Owner decision: approved
- ID: D-002
  - Title: Hệ thống pill trạng thái
  - Description: Chuẩn hóa pill trạng thái Active/Draft/Hidden cho các màn hình admin.
  - Scope impact: Style trạng thái và nhãn i18n.
  - Related screens/features: Admin Services, các list admin khác.
  - Trade-offs: Thêm công việc design system vs. nhất quán.
  - Estimated complexity: Medium
  - Status: approved
