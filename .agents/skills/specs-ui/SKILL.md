# UI Spec Template (specs/<feature>/ui.md)

## Sections
- Overview (screen list + intent)
- Navigation and entry points
- States (loading/empty/error/success)
- Forms and validation rules
- Accessibility notes
- i18n keys (new/updated)

## Rules
- Keep `spec.md` focused on product requirements.
- Put UI layout/state/interaction details here.
