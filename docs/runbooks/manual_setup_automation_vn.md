# Runbook tự động hóa thiết lập

## Mục đích
Mô tả cách chạy tự động hóa thiết lập và xác minh cấu hình môi trường.

## Checklist
- Điền giá trị env trong `.env` hoặc file cấu hình liên quan.
- Chạy script theo đúng thứ tự.
- Xác minh triển khai và quyền truy cập.

## Ghi chú
- Giữ các bước thủ công tại `docs/delivery/manual_setup.md`.
