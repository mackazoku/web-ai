# Web AI Documentation

## Purpose
Central index for Web AI product, design, and delivery documentation.

## Structure
- `docs/specs/` Product requirements and brainstorming.
- `docs/design/ui/` UI specs and screen references.
- `docs/design/system/` System, API, and data model specs.
- `docs/plan/` Implementation planning and status tracking.
- `docs/delivery/` Execution logs, test plans, and manual setup steps.

## Rules
- English is the source of truth.
- Every document under `docs/` must have a Vietnamese version with `_vn` suffix.
