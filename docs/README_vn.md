# Tài liệu Web AI

## Mục đích
Chỉ mục tài liệu trung tâm cho sản phẩm, thiết kế và triển khai Web AI.

## Cấu trúc
- `docs/specs/` Yêu cầu sản phẩm và brainstorming.
- `docs/design/ui/` Đặc tả UI và tham chiếu màn hình.
- `docs/design/system/` Đặc tả hệ thống, API và mô hình dữ liệu.
- `docs/plan/` Kế hoạch triển khai và theo dõi trạng thái.
- `docs/delivery/` Nhật ký thực thi, kế hoạch kiểm thử và bước thiết lập thủ công.

## Quy tắc
- Tiếng Anh là nguồn chuẩn.
- Mỗi tài liệu trong `docs/` phải có bản tiếng Việt với hậu tố `_vn`.
